# IntentTrace 0.1.0-preview.1

Experimental research preview, November 9, 2026. This is not a stable API release.

## Run It

Requires Git, JDK 17, Python 3.9+, and network access for the first Gradle build.

```bash
git clone https://github.com/syellanki09/intenttrace.git
cd intenttrace
git checkout v0.1.0-preview.1
python3 tools/run_preview.py
```

The command runs the Kotlin and Python suites, executes both demonstrations,
independently checks their outputs, and creates a combined evidence pack.

## Expected Results

- Stale context: fresh control is SATISFIED; pinned older context is VIOLATED.
- Duration contracts: coordinated upgrade is SATISFIED; cross-version unit drift
  and same-version semantic drift are VIOLATED.
- All five detection observations are null. Ground truth is not system detection.

## Evidence

The release attachment `preview.zip` contains the exact source SHA, runtime,
raw JSONL records, independent evaluation summaries, evidence checksums, a
verified stale-context bundle, and build/test logs. `report.json` exposes the
same summary without unpacking. `SHA256SUMS` checks attachment integrity;
it is not a signature or an authenticity guarantee. GitHub source archives
are source distributions, not the verified evidence pack.

See the [walkthrough](../preview-walkthrough.md) for inspection and feedback.

## Limitations

Only stale-context and synthetic duration-contract demonstrations are runnable.
Other taxonomy scenarios, production integrations, and an independent detector
are not implemented. APIs and schemas may change. Runtime metadata and logs
can vary across reproductions. No production prevalence, external adoption,
independent human reproduction, DOI, or archival deposit is claimed.
